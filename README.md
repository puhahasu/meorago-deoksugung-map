# 머라고 · 덕수궁 맵 현장 프로토타입

QR로 맵을 열고 장소를 선택해 미리 작성된 쉬운 설명을 읽는 정적 웹사이트입니다.

## 실행

빌드·패키지 설치·API 키·서버 프로그램이 필요 없습니다. GitHub Pages에서 main 브랜치의 루트(`/`)를 게시합니다. 로컬에서는 이 폴더에서 `python3 -m http.server 8773`을 실행합니다.

- 지도 이름 터치 → 핵심 설명 → 상세·각주 펼침
- 하단 고스트 링크 → 맵으로 복귀
- 지도 확대/축소 및 확대 후 스크롤
- 같은 탭에서 맵 위치·읽던 위치·상세 펼침 상태 유지 (sessionStorage를 사용할 수 없는 환경에서도 기본 읽기는 가능)
- 장소별 직접 링크: `#entrance`, `#junghwajeon`, `#haenggak`, `#jeukjodang`, `#hamnyeongjeon`, `#gwangmyeongmun`, `#jeonggwanheon`, `#seokjojeon`, `#dondeokjeon`, `#jungmyeongjeon`

## 실행 중 AI를 사용하지 않습니다

지도, 콘텐츠, CSS와 JavaScript를 같은 사이트에서 불러옵니다. 촬영·OCR·생성·외부 API·서버·사용자 계정·분석 로그를 사용하지 않습니다. 최초 로딩에는 인터넷이 필요하며 완전 오프라인을 보장하지 않습니다. 자료 출처 링크는 사용자가 선택할 때만 외부 페이지로 이동합니다.

## 콘텐츠 상태

총 10곳의 기존 문안을 연결했습니다. 신규 문안 자동 생성은 하지 않았습니다.

| 장소 | 문안 상태 |
|---|---|
| 덕수궁 입구 | V0.3 확정 문안 |
| 중화전 일원 | V0.1 저장 기준 문안 |
| 중화전 행각 | 복구한 검토 초안 |
| 즉조당 일원 | V0.1 검토 초안 |
| 함녕전·덕홍전 | 원문 일부 미판독을 영문 등으로 보충한 검토 초안 |
| 광명문 | 옛 위치 안내판을 복귀 자료로 보충한 검토 초안 |
| 정관헌 | 용도 전승의 불확실성을 각주에 남긴 검토 초안 |
| 석조전 일원 | V0.1 검토 초안 |
| 돈덕전 | 원문 일부 미판독을 영문·공식 자료로 보충한 검토 초안 |
| 중명전 일원 | 2014년 안내판 기준 V0.1 검토 초안 |

초안의 존재, 원문 판독, 사실 검토, 사용자 승인, 현행 안내판 일치, 현장 테스트 완료는 서로 다릅니다. 8곳을 승인 완료나 검증 완료로 표시하지 않습니다. `content.js`에 각 문안의 검토 메모와 기존 참고 URL을 보존했습니다. 해당 내용은 제작자 기록에만 보존하고 관람객 화면에는 표시하지 않습니다.

2026-10-20 과거 ‘덕수궁 프로젝트’ 대화의 파일 생성 기록에서 추가 8곳 문안을 복구했습니다. ‘광명문’의 제작자 지시형 문장은 당시 후속 수정 기록을 적용했습니다. 이 복구 작업에서 역사적 내용을 새로 검증하거나 임의로 다시 쓰지 않았습니다.
